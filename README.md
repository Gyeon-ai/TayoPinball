# 타요의 종겜핀볼

SOOP 라이브 채팅과 후원 내역에서 핀볼 추첨에 사용할 목록을 수집하는 Windows 프로그램입니다.

**바로 다운로드:** [자동판](https://github.com/Gyeon-ai/TayoPinball/raw/refs/heads/main/%ED%83%80%EC%9A%94%EC%9D%98%20%EC%A2%85%EA%B2%9C%ED%95%80%EB%B3%BC%28%EC%9E%90%EB%8F%99%29.exe) / [일반판](https://github.com/Gyeon-ai/TayoPinball/raw/refs/heads/main/%ED%83%80%EC%9A%94%EC%9D%98%20%EC%A2%85%EA%B2%9C%ED%95%80%EB%B3%BC.exe)

## 일반판과 자동판

- **일반판:** 수집한 목록을 복사하거나 저장하고 핀볼 사이트를 엽니다.
- **자동판:** 일반판 기능에 더해, Chrome으로 핀볼 사이트를 열 때 수집한 목록의 입력칸 자동 반영을 시도합니다.

## 사용 방법

1. 방송 주소 또는 SOOP ID를 입력하고 수집을 시작합니다.
2. 수집 대상(별풍선·애드벌룬·도전미션), 후원 개수 조건, 닉네임·채팅 내용 반영 방식을 선택합니다.
3. 수집된 목록을 확인한 뒤 복사하거나 메모장에 저장하고, [타요 핀볼 사이트](https://gyeon-ai.github.io/TayoPinball-Web/)에서 사용합니다.

처음에는 위 링크에서 새 버전을 직접 받아야 합니다. 이후 새 버전이 나오면 프로그램에서 **업데이트 / 나중에**를 선택할 수 있습니다.

## 패치 내역

### 1.4.4.6

- 업데이트 안내창의 글씨와 정렬을 개선하고 둥근 버튼을 적용했습니다.
- 수집된 내용과 코인, 설정 영역의 가독성을 조정하고 내용 복사·메모장 저장 버튼의 글씨를 보강했습니다.
- 긴 닉네임을 위한 후원 정보 글씨 크기와 수동 테스트·모두 지우기 버튼은 유지했습니다.
- 기존 화면 문구와 수집 조건, 10회당 1코인 추가 규칙은 그대로입니다.

### 1.4.4.4

- 창 너비나 높이가 작을 때 하단 버튼과 설정 영역이 잘리는 문제를 수정했습니다.
- 코인 합계가 커져도 숫자와 단위가 보이도록 표시 영역을 개선했습니다.
- 수집 목록에서 이름과 코인을 편집할 때 입력칸의 세로 정렬을 맞췄습니다.
- 기존 화면 문구와 글꼴, 수집 조건 및 코인 계산 규칙은 유지했습니다.

### 1.4.4.3

- 일반판과 자동판에 새 버전 확인 및 업데이트 선택 기능을 추가했습니다.
- 업데이트 파일을 검증하고, 적용에 실패하면 기존 프로그램을 복구하도록 했습니다.

### 1.4.4.2

- `정확히 N개` 조건에서 후원 개수가 N의 배수이면 해당 배수만큼 코인을 반영하도록 수정했습니다. 예를 들어 N=200이면 400개는 2코인입니다.
- 수집 대상 선택 창의 반응과 수집 목록의 표시·스크롤을 개선했습니다.
